# 🪸 CoraVera

## 🌊 Descripción

CoraVera es un videojuego educativo desarrollado como proyecto universitario por el equipo INNDI.

El proyecto busca generar conciencia sobre la importancia de los arrecifes de coral y promover su conservación mediante una experiencia interactiva y educativa.

## 🎮 Características

- Exploración de un entorno submarino en 3D.
- Recolección de basura marina.
- Curación de corales mediante mecánicas interactivas.
- Sistema de niveles y misiones.
- Sistema de registro e inicio de sesión.
- Almacenamiento del progreso y estadísticas del jugador.
- Integración con Firebase.

## 📊 Datos registrados

El sistema permite registrar información relacionada con el progreso del jugador, como:

- Tiempo de juego.
- Basura recolectada.
- Corales curados.
- Nivel completado.

## 🛠️ Tecnologías utilizadas

- Unity
- C#
- Firebase
- Git
- GitHub

## 🎯 Objetivo

Utilizar los videojuegos como una herramienta educativa para fomentar el conocimiento y la conciencia sobre la conservación de los ecosistemas de coral.

## 👥 Equipo

### INNDI

Proyecto desarrollado como parte de las actividades académicas de la carrera de Ingeniería en Entornos Virtuales y Negocios Digitales.
